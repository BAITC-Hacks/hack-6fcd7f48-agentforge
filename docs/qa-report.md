## Найдено и исправлено

- **P2 — компоненты:** `summary.n_components` исключал изоляты. Граф с одним связным фрагментом и одним seed-изолятом давал 1 вместо 2. Backend исправлен на полный подсчёт; на официальном наборе 35 компонент, включая 19 изолятов. Упомянутые в ТЗ 16 — компоненты с рёбрами.
- **P2 — переполнение сумм:** две отдельные конечные транзакции по `1e308` давали `summary.sum_kzt=Infinity` и `node.in_kzt=Infinity`, что нарушало JSON контракт. Backend теперь отклоняет такие входы с понятным `ValueError`; регрессия проходит.
