# Критерии кейса и подтверждение

Матрица фиксирует локальную приёмку чистой копии: реализацию, проверку, доказательство и статус на момент проверки. Удалённый fresh clone и CI не подтверждены; после публикации актуальный запуск будет доступен в [GitHub Actions](../../../actions/workflows/verify.yml), workflow описан в [verify.yml](../.github/workflows/verify.yml).

## Вес критериев

Соответствие задаче и работоспособность — 25 баллов; техническая реализация — 25; README и воспроизводимость — 25; ценность и применимость — 15; потенциал развития и оригинальность — 10. Это веса из задания, не оценка команды.
