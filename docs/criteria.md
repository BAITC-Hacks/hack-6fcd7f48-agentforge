# Критерии кейса и подтверждение

Таблица относится к текущей локальной версии. Команды и подробности проверок собраны в [QA-отчёте](qa-report.md); расчётные правила и ограничения — в [методологии](methodology.md).

| Критерий | Реализация | Проверка | Свидетельство | Статус |
|---|---|---|---|---|
| Воспроизводимый расчёт трёх Parquet | Локальный CLI валидирует вход и создаёт три CSV | Полный CLI на официальном наборе | 2 248 узлов, 3 119 рёбер, 4 840 транзакций; текущий расчёт в `analyze` — около 0,51 с, полный CLI — около 1 с | PASS локально |
| Структурные роли для всех узлов | Шесть упорядоченных правил, отдельная `collector_shape` и объяснимый `role_score` | 32 Python-теста; регрессии правил и границ score | Каждому из 2 248 узлов назначена роль; роли остаются гипотезами без ground truth | PASS |
| Coordinator и consolidator | Coordinator получает от двух или более непосредственных узлов формы сбора; consolidator соответствует самой форме | Синтетические проверки и расчёт на официальных данных | 265 consolidator и 2 coordinator; реальные примеры описаны в README и методологии | PASS; метки не являются доказанными ролями |
| Приоритет кандидатов | Четыре нормированных компонента, поправка seed/boundary; роль и PageRank не дают бонуса | Проверка компонентов, сортировки и seed-путей | В top-20: 18 consolidator, 1 peripheral, 1 distributor; seed нет | PASS как реализация эвристики; точность не измерена |
| Кластеры и компоненты | Взвешенное Louvain-разбиение и weak components, включая isolates | Сверка на официальном наборе | 91 кластер; 35 компонент, из них 16 с рёбрами и 19 изолятов | PASS |
| Объяснимость и границы | Evidence, разбор приоритета, до трёх путей от seed, предупреждения о seed/boundary и превышении выхода над входом | API/JSON и regression-проверки | Пути монотонны по depth; координаторские примеры имеют реальные наблюдаемые ветви; API указывает неполный баланс | PASS; финансовая атрибуция отсутствует |
| CSV и API | Три фиксированные CSV-схемы; API возвращает экспорт из расчётного снимка в памяти | Сверка схем, строк и HTTP body в интеграционной проверке | `nodes_roles.csv` — 2 248 строк, `clusters.csv` — 91, `top_nodes.csv` — 100; API-байты совпали с CSV расчёта | PASS в интеграционной проверке |
| Интерфейс и запуск | React/Cytoscape UI, локальный режим и Docker Compose | 5 frontend-тестов, lint, typecheck, production build; сценарии браузера описаны в QA | В прежнем интеграционном проходе проверены desktop/mobile, граф, поиск, карточки и скачивание CSV | PASS для указанных сценариев |
| Проверки кода | Backend и frontend имеют автоматические тесты и линтеры | `pytest`, Ruff, frontend test/lint/typecheck/build | 32 Python-теста прошли за 2,16 с; Ruff PASS; frontend 5 tests и все названные проверки PASS | PASS локально |
| Интерпретация результатов | Документированы неполная сеть, глубина 4 и отсутствие эталонных меток | README и методология сверены с правилами обработки | 2 248 узлов, 81 seed, 444 boundary; роли и scores не трактуются как виновность | Документировано |
| Рост до миллиона узлов | Определены возможные направления оптимизации | План описан отдельно; измерений на миллионе нет | Колончатые агрегаты, CSR/igraph, приближённые метрики и ограниченная отрисовка | Не реализовано; не заявляется как поддержанный масштаб |

Числа по ролям для текущего расчёта: 265 consolidator, 68 transit, 118 distributor, 936 terminal, 2 coordinator и 859 peripheral. Сумма — 2 248. Частоты отражают только правила на данном наборе; без проверенных экспертных меток они не показывают качество или истинность классификации.

Вес критериев из задания: соответствие задаче и работоспособность — 25 баллов; техническая реализация — 25; README и воспроизводимость — 25; ценность и применимость — 15; потенциал развития и оригинальность — 10. Это веса задания, не оценка команды.
